# The Air We Inherit

A scrollytelling website on environmental injustice in West Oakland: how
historical redlining, the growth of the Port of Oakland, and decades of zoning
decisions shape who breathes diesel today.

west-oakland-air-justice/
├── index.html           Main scrollytelling page — 7 chapters + appendix
├── css/styles.css       Palette, typography, layout, breathing/lungs styles
├── js/
│   ├── scroll.js        Intersection-observer reveal on each chapter
│   ├── map.js           Leaflet: HOLC polygons × CalEnviroScreen × port corridor
│   ├── charts.js        Chart.js: race, income, pollution comparison bars
│   ├── breathing.js     SVG "breathing timeline" — asthma rates by decade
│   └── lungs.js         Two animated lungs breathing at different capacities
├── data/                Placeholder JSON + README on how to replace with real data
└── assets/              (reserved for images / extra media)
